# Format research for Phases 13–16 (2026-10-22)

Web research (minecraft.wiki, NeoForged docs) cross-checked where possible against the 26.3 client
jar (classes read with `javap`, vanilla JSON counted locally — reference only, nothing copied).
"✔ jar" = confirmed in the 26.3 code or data.

## Item model definitions `items/*.json` (Phase 14)

Root: `model`, `hand_animation_on_swap` (1.21.4), `oversized_in_gui` (1.21.6), `swap_animation_scale`
(25w41a → 1.21.11). Types: `model` (model, tints), `composite` (models), `condition` (property,
on_true, on_false), `select` (property, cases {when: value | list, model}, fallback),
`range_dispatch` (property, scale, entries {threshold, model}, fallback), `empty`,
`bundle/selected_item`, `special` (model {type…}, base). `transformation` on any object except
`empty`/`bundle/selected_item` (26.1).

Specials: banner, bell (26.1), book (26.1), chest (`chest_type` 26.1), conduit, copper_golem_statue,
decorated_pot, end_cube (26.1), head, player_head (1.21.6), shield, shulker_box, trident. Removed:
`bed` (26.2), `standing_sign`/`hanging_sign` (26.2).

Properties — condition: broken, bundle/has_selected_item, carried, component, custom_model_data
(index → flags), damaged, extended_view, fishing_rod/cast, has_component, keybind_down, selected,
using_item, view_entity. Select: block_state, charge_type, component, context_dimension,
context_entity_type, custom_model_data (strings), display_context, local_time, main_hand,
trim_material. Range: bundle/fullness, compass (target, wobble), cooldown, count, crossbow/pull,
custom_model_data (floats), damage, time (source, wobble), use_cycle, use_duration.
Tints: constant, custom_model_data, dye, firework, grass, potion, team (`map_color` removed in 26.3
per the wiki history — provisional). Display contexts: none, thirdperson__, firstperson__, head,
gui, ground, fixed, on_shelf.

26.3 jar, 1658 definitions: model 2253, select 71, special 91, composite 34, condition 26,
range_dispatch 8, bundle/selected_item 17; tints dye 50, constant 11, grass 6, potion 4, firework 1.
Old `overrides` were removed in 1.21.4: CMD float → `range_dispatch` on `custom_model_data`.

## GUI sprites (Phase 15)

`textures/gui/sprites/…` (1.20.2, format 18). `.png.mcmeta` `gui.scaling`: `stretch` (default),
`tile` {width, height}, `nine_slice` {width, height, border: n | {left, top, right, bottom},
`stretch_inner` (default false, ~1.21.2)}. Sprite lists per version: only from the client jar.

## Equipment and trims (Phase 16)

`assets/<ns>/equipment/<id>.json` (1.21.4; `models/equipment` in 1.21.2–3): `layers` {type → [
{texture, dyeable {color_when_undyed}, use_player_texture}]}, `trim_overrides` (26.3 snapshot 6,
was `trim_palette_replacements`). Texture `ns:path` → `textures/entity/equipment/<type>/<path>.png`.
Types: humanoid, humanoid_leggings, humanoid_baby (26.1), wings, wolf_body, horse_body, llama_body,
happy_ghast_body (1.21.6), nautilus_body (1.21.11), saddles (1.21.5; nautilus/camel_husk 1.21.11).
26.3 trims: palettes in `textures/palettes/trim/<name>.png`, base `textures/palettes/trim_base.png`,
entity trims made on demand from a `palette` mcmeta section {base_palette}; items still use
`paletted_permutations`. To verify in the jar before building on it: the pre-26.3 palette folder
name, the humanoid 64×32 layout.

## Emissive overlays (Phase 18)

`<name>_e.png` drawn fullbright over the texture (no darkness, same render layer; on solid textures
as cutout); alpha scales brightness. Suffix `_e` unless `assets/minecraft/optifine/emissive.properties`
sets `suffix.emissive`. OptiFine: blocks, items, mobs, block entities; Continuity: blocks and items;
ETF: entities only. Shader packs read the LabPBR `_s` alpha instead; some (Complementary) warn of
double glow with emissive packs → ship `_e` as an option. Unverified: Continuity/ETF need the
properties file, animation rules for `_e`.
