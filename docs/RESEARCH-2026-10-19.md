# Code audit + feature-gap research (2026-10-19, before Phase 12)

Goal: review all the source code, then research resource-pack tutorials and tools on the
web to find what is missing before calling PackForge feature-complete.

## 1. Code audit (src/main, shared, preload, renderer — read-only)

`npm run check` passes (732 tests). The overall picture is good: IPC arguments re-validated in main,
realpath containment everywhere, pure logic split out and tested, request counters against async races,
backup + confirmation on every bulk write, LabPBR decoding matches the spec, model geometry
(default UVs, face rotation, rescale, X-then-Y state rotation, multi-axis 1.21.11 rotation,
`shade_direction_override`) matches vanilla. The weak spots are **concurrency in main** and the
**lifecycle of TextureEditor.tsx**.

Verified by reading the code (✔ = re-checked by hand in this session):

### High

| #    | Where                                                                        | Defect → failure                                                                                                                                                                                                                                                                                 |
| ---- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A1 ✔ | `main/backups.ts` restore → create → prune                                   | With 50 backups, restoring the oldest: the "Prima di ripristinare" backup prunes it, the restore fails with ENOENT and that backup is gone. Read the files first or don't prune the id being restored.                                                                                           |
| A2   | `textureFile.ts`, `drafts.ts`, `editMcmeta.ts`, `packIcon.ts`, `exporter.ts` | Fixed temp name `${file}.tmp`: two overlapping writes of the same file (double Ctrl+S, batch + save, slow autosave) can rename a mixed/corrupt file or fail. Unique temp names + per-path write queue.                                                                                           |
| A3   | `main/editMcmeta.ts`                                                         | Read-modify-write without a lock: description and version edits at the same time → one is lost. Serialize like `SettingsStore.modify`.                                                                                                                                                           |
| A4 ✔ | `editor/PixelCanvas.tsx` keydown                                             | No `suspended` gate: on the Prova screen Ctrl+Z/Y undo/redo the hidden texture, Space is swallowed; behind dialogs Delete/Esc act on the selection.                                                                                                                                              |
| A5   | `editor/TextureEditor.tsx` load effect (`tallKey`)                           | The editor reloads in place (plant shape → Alta, whole/half toggle after a failed save) without remount: unsaved strokes dropped, History/animation/surface stale (Ctrl+Z into dead buffers). Key the editor on `tallKey` too; continue only if the save succeeded.                              |
| A6   | `TextureEditor.tsx` tall mode                                                | `surface` not reset to color in "Pianta intera": painting a hidden `_n`/`_s` and the tall save never writes maps → edits lost.                                                                                                                                                                   |
| A7 ✔ | `preview/BlockPreview.ts` `prepareSsr`                                       | `ssrDepth/ssrColor` still bound to `composer.base` while rendering into it → feedback loop, the draw is skipped from frame 2: screen-space reflections silently fall back to the capture (screenshots too). Null them before `setRenderTarget(base)` — same trap as the bloom pass.              |
| A8 ✔ | `shared/plantShapes.ts`                                                      | Generated plant models only write `shade_direction_override` (26.3+). Vanilla `block/crop` up to 26.2 uses `"shade": false`; packs targeting 1.21.x–26.2 get directionally shaded plants in game. Write `shade: false` for formats before 26.3 (or both, if 26.3 ignores the old field — check). |

### Medium

- A9 `main/ipc.ts`: switching pack does not clear the pending auto-sync timer → the new pack can be mirrored into resourcepacks without consent; `sync:now` and the timer can run `mirrorPack` concurrently (EBUSY on Windows turns auto-sync off); overlapping `pack:open` can leak a watcher on the wrong pack.
- A10 `main/packSync.ts`: case-only rename (Stone.png → stone.png) on Windows: copy skipped, target deleted → texture missing in game until next sync.
- A11 `shared/pngCodec.ts`: `unzlibSync` without an output cap (decompression bomb in main). Pass the expected size.
- A12 `shared/animation.ts:54`: with only `width` or only `height`, our default for the other side follows the wiki's odd wording (already flagged "suspicious" in the code). The audit believes the game uses the image's own side. **Verify on decompiled `calculateFrameSize` before changing.**
- A13 Editor: tall plants have no draft and no external-change watch; drafts keep only the flattened albedo (painted maps/layers not recoverable); merge-down ignores the lower layer's opacity/visibility (saved PNG changes); add/remove frames doesn't restructure `_n`/`_s`; "Togli animazione" is not an undo step.
- A14 Editor performance on 128×+: every pointer move recomposites and syncs all 7 channel proxies, re-runs palette/advice, re-renders an uncapped swatch grid.
- A15 `ResizeDialog`/`ValidatorDialog`: re-scan the whole pack on every watcher bump while writing (N writes → N full scans); `cancelled` only checked at the end.
- A16 No WebGL context-loss handling (preview black until remount).

### Low (robustness)

Plain `rename` instead of `renameRetrying` in 4 writers; `:` accepted in pack paths (NTFS streams —
containment still protects); `mkdir` before the containment check in `packSync.ts:105`; `buildExport`
doesn't re-enforce the vanilla-copy check; `scaleMcmeta` can write non-integer frame sizes; ignored
results (`texture:saveMcmeta` in Resize/Variants, `project:save` in Export, `save().then` in 4 places →
one `saveThen()` helper); double-click can start two batch/CTM/variant runs; stale growth tabs after
switching the preview to Cubo; scene change during load uses the old layout; TutorialCard IPC write
inside a setState updater; SettingsPanel stuck on "Caricamento" if `settings:get` fails.
Untested orchestration: `main/ipc.ts` (sync, open, watch), `packWatcher.ts`.

Cleanup: unused bloom target `up[LEVELS-1]`, per-part geometry only needed for held items, duplicated
day/night effect (PreviewPanel/TestScreen), duplicated DDA setup in `block.frag.glsl`, duplicated
image-loading helpers, orphaned doc comments (`TextureEditor.tsx` ~1596, `BlockPreview.ts` ~483).

theme — bigger than full retextures. PackForge is very strong in PBR/CTM, which is the smallest niche
by count. The large segments we don't serve: **3D block/item models, item display transforms,
GUI, items/armor (equipment, trims), emissive, sky**.

## 3. What tutorials teach vs PackForge

Covered: setup + pack.mcmeta + pack.png, structure/namespace, texture editing with the vanilla
reference, pixel-art craft (ramps, hue shift, palettes, 3×3 tiling), animation mcmeta, blockstates for
variants, in-game testing, distribution zip, CTM, LabPBR.

Not covered (taught by tutorials / used by popular packs):

- **Block/item model editing** (elements, per-face UV, `display` transforms) — today only Blockbench.
- **Item model definitions** `assets/<ns>/items/*.json` (1.21.4+, 24w45a): types `model`, `composite`,
  `condition`, `select`, `range_dispatch`, `empty`, `bundle/selected_item`, `special`; root fields
  `hand_animation_on_swap`, `oversized_in_gui` (1.21.6), `swap_animation_scale` (1.21.11),
  `transformation` (26.1). Source: minecraft.wiki/w/Items_model_definition.
- Items: our preview shows the generated plate and the inventory slot only; no `items/` reading.
- **GUI sprites** (`textures/gui/sprites`, `.png.mcmeta` `gui.scaling` stretch/tile/nine_slice).
- **Equipment/armor** (`equipment/*.json`, humanoid layers), **trims** (26.3 moved palettes to
  `textures/palettes/trim/`, new `.mcmeta` `palette` section).
- Entity textures (with model UV template), paintings, particles, sky (sun/moon, OptiFine sky), colormaps editor.
- Sounds (`sounds.json`, .ogg), lang files, fonts (bitmap providers) — audio/locale/fonts are small segments.
- Server-pack distribution (SHA-1, `resource-pack=` URL), size optimizer (PackSquash-style).

## 4. Mod-based features (Modrinth, 2026-10)

Maintained for 26.3: Iris 193M, ETF 110M, EMF 104M, Continuity 79M, Polytone 19M, Animatica
Refabricated 5M. CIT Resewn original is dead (last 1.21.1); its continuation is small (285K).
OptiFine lags behind (third-party sources: 26.1.2). Feasible for us:

- **Emissive `_e` textures** (Continuity blocks, ETF entities): easy, we already have the LabPBR emission channel.
- OptiFine/ETF **random textures** naming (`stone2.png`…): fits our variants picker.
- Colormaps / Polytone biome colors: fits our tint preview.
- Custom sky (`optifine/sky/world0/skyN.properties`): medium.
- CEM/EMF entity animation: leave to Blockbench. CIT: prefer vanilla `items/` definitions.

## 5. Format changes 2025–2026 worth tracking (minecraft.wiki)

Latest release 26.3 (2026-09-15, resource format 97.1); 26.4 in snapshots. 1.21.11: multi-axis
element rotation, no ±45° limit, blockstate `z`; `.mcmeta` `alpha_cutoff_bias`, `mipmap_strategy`.
26.1: model texture objects (`force_translucent`), item `transformation`, special `bell`/`book`/`end_cube`.
26.2: beds as block models (`beds` atlas removed), special `bed`/sign types removed. 26.3: `shade` removed
from block elements → `shade_direction_override` (see A8), trim palettes moved, OIT shaders,
`#include` instead of `#moj_import`, always-on `minecraft:end_of_frame` post effect.
To check against our code: `mipmap_strategy`/`alpha_cutoff_bias` in the preview mipmaps, `force_translucent`.

## 6. Proposed new tracks

Ranked by value for users ÷ effort, given what PackForge already has:

1. **Fix pass** (A1–A8 + the medium list) — before any new feature.
2. **3D models ("Modelli 3D")** — the most-asked-for theme:
   - a. Extrude a texture to a thick 3D item/block model (greedy-merged cuboids, element budget).
   - b. "Pixels that pop out" for ores/details: pick pixels by color/selection → raised cuboids with UVs.
   - c. Parametric 3D presets: torch, lantern/chain, ladder, rails, bushy leaves, grass sides.
   - d. Simple element editor (list + from/to/rotation/per-face UV, gizmo in the preview) with
     validation per pack format; display transforms editor (gui/hand/ground/head/fixed/on_shelf)
     with the held/slot views we already have. "Low fire / low shield" style tweaks fall out of this.
   - e. Element/face cost advisor (like the texture advice).
3. **Items done properly**: read and preview `items/*.json` (select on display_context, condition,
   range_dispatch for bows/compass), a small definition editor, 2D-in-GUI / 3D-in-hand in one click.
4. **Pack Doctor + version port**: diff two client jars (textures added/renamed/removed, renames by
   pixel hash), "missing in my pack" for the target version, migrate old `overrides` → `items/`,
   lint for wrong names/case/paths that the game silently ignores, nested-folder zip.
5. **Emissive `_e`** from the LabPBR emission channel (+ preview toggle); random-texture naming for OptiFine/ETF.
6. **GUI sprites**: nine-slice/tile editor with scale preview 1–4, dark-mode style batch recolor.
7. **Equipment/armor + trims** (26.3 palette layout), entity texture painting on a UV template (later).
8. Smaller: palette import/export (.gpl/.hex, Lospec), adjustment filters (hue/sat, levels) per layer
   and in batch, PNG optimizer on export, sky/sun/moon, sounds/lang (low demand).

Not recommended: generative AI (Modrinth/CurseForge/Faithful communities are hostile), entity
animation (Blockbench + EMF already serve it), core shader editing (breaks every version).
